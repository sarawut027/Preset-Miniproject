## ⌨️ ปุ่มควบคุมการนำเสนอ (Presentation Controls)
* **เลื่อนสไลด์:** ปุ่มลูกศร `→` / `←` หรือ `Spacebar` หรือ `PageDown` / `PageUp`
* **หน้าแรก / หน้าสุดท้าย:** `Home` / `End`
* **เต็มจอ (Fullscreen):** กดปุ่ม `F`
* **เปิดสารบัญสไลด์ (Drawer):** กดปุ่ม `M` หรือ `O` หรือคลิกปุ่ม **"▦ สารบัญ"** ที่แถบด้านล่าง
* **ซูมดูรูปไดอะแกรม (Zoom Modal):** คลิกที่รูปภาพไดอะแกรมในสไลด์เพื่อขยายดูรายละเอียดคมชัด และกด `Esc` เพื่อปิด
* **เปิดชิ้นงานจริง:** คลิกปุ่ม **📱 LIFF Demo** หรือ **💻 Admin Demo** จากแถบควบคุมด้านล่างได้ทันที
