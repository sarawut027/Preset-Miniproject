7204903 โครงงานด้านเทคโนโลยีสารสนเทศ 2 • IT NPRU

การนำเสนอสรุปโครงงาน: ระบบบริหารรายได้และค่าคอมมิชชันช่างตัดผมผ่านไลน์

LINE-Based Barbershop Income and Commission Management System
ผู้จัดทำ: นาย สราวุฒิ อุยยาหาญ (รหัสประจำตัว 674230027, หมู่เรียน 67/44)
สาขาวิชาเทคโนโลยีสารสนเทศ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏนครปฐม

⚠️ ที่มาและความสำคัญของปัญหา (Problem Statement)

การวิเคราะห์ปัญหาและแนวคิดการแก้ไขปัญหา (Fishbone Diagram) ตามนายสราวุฒิ อุยยาหาญ (2570)

SLIDE 02 / 07
💸 1. ปัญหาด้านรายรับ (เงินเข้า)
  • ตรวจสอบสลิปขณะติดลูกค้า: ช่างหรือเจ้าของร้านติดภารกิจตัดผม ไม่สามารถเปิดแอปธนาคารตรวจยอดเงินได้ทันที
  • ความเสี่ยงสลิปปลอม/วนใช้ซ้ำ: เสี่ยงต่อการถูกฉ้อโกงด้วยภาพสลิปตัดต่อ และการนำสลิปเก่ามาวนใช้ซ้ำ
  • โอนยอดไม่ตรง: ลูกค้าโอนเงินไม่ตรงตามราคาค่าบริการจริงโดยไม่สามารถตรวจจับได้ทันท่วงที
🤝 2. ปัญหาการเคลียร์เงินช่าง (เงินออก)
  • คำนวณส่วนแบ่งด้วยมือ: สิ้นวันต้องคิดค่าคอมมิชชันด้วยตนเอง มักเกิดข้อผิดพลาดจากการคำนวณของมนุษย์
  • ขาดการแจ้งเตือนเรียลไทม์: ช่างตัดผมไม่สามารถตรวจสอบยอดเงินสะสมได้ในระหว่างวัน ทำให้เกิดความเคลือบแคลงสงสัย
  • การตัดรอบเคลียร์เงินล่าช้า: ขาดระบบสรุปยอดค้างเคลียร์ (Settlement) และแนบหลักฐานการโอนจ่ายช่างที่ชัดเจน
🗄️ 3. ขาดระบบจัดการและรายงานธุรกิจ
  • บันทึกในสมุด/ตารางคำนวณ: ข้อมูลสูญหาย รายการตกหล่น และขาดระบบฐานข้อมูลกลาง (CRUD) ในการจัดการ
  • ขาดใบเสร็จรับเงินที่น่าเชื่อถือ: ไม่มีระบบออกใบเสร็จรับเงินอิเล็กทรอนิกส์ (e-Receipt) ให้แก่ลูกค้า
  • ขาดเครื่องมือวิเคราะห์ผู้บริหาร: เจ้าของร้านขาดแดชบอร์ดสรุปผลประกอบการ ยอดขาย และผลงานช่างในภาพรวม

🎯 วัตถุประสงค์ของโครงงาน (Project Objectives)

5 วัตถุประสงค์หลักของระบบตามเอกสารวิชาการโครงงาน (ข้อ 1.3.1 - 1.3.5)

SLIDE 03 / 07
1. ระบบรับชำระเงินผ่าน LINE LIFF (1.3.1)

ระบบรองรับการทำรายการของผู้ใช้งาน โดยสามารถเลือกบริการ เลือกช่างตัดผม และอัปโหลดหลักฐานการโอนเงินผ่านทางหน้าเว็บแอปพลิเคชัน LIFF (LINE Front-end Framework) บนแอปพลิเคชัน LINE

2. ตรวจสอบสลิปอัตโนมัติ Slip2Go API (1.3.2)

ระบบมีฟังก์ชันตรวจสอบความถูกต้องของสลิปโอนเงินโดยอัตโนมัติ ผ่านการเชื่อมต่อกับระบบ Slip2Go API ตรวจสอบยอดเงิน บัญชีผู้รับ และป้องกันสลิปใช้ซ้ำ

3. คำนวณส่วนแบ่งช่าง & ฐานข้อมูล MySQL (1.3.3)

ระบบสามารถคำนวณส่วนแบ่งรายได้ของช่างตัดผม และบันทึกข้อมูลประวัติการทำธุรกรรมทั้งหมดลงในระบบฐานข้อมูล MySQL โดยอัตโนมัติ

4. ส่ง Flex Message & แจ้งเตือนเรียลไทม์ (1.3.4)

ระบบสามารถส่ง เฟล็กซ์เมสเสจ (e-Receipt) ให้แก่ลูกค้า พร้อมทั้งแจ้งเตือนสรุปยอดเงินให้ช่างตัดผมและเจ้าของร้านทราบ ผ่านทางแอปพลิเคชัน LINE

5. กระดานข้อมูลสรุปยอดขาย Data Studio (1.3.5)

ระบบมีหน้ากระดานข้อมูล (Dashboard) สำหรับแสดงผลสรุปยอดขาย สถิติการใช้บริการ และรายได้ของช่างตัดผมแต่ละรายแบบเรียลไทม์ ผ่านเครื่องมือ Data Studio (Google Looker Studio)

📐 ขอบเขตของระบบ (System Scope)

ขอบเขตฟังก์ชันการทำงานครอบคลุม 3 กลุ่มผู้ใช้งานหลักตามเอกสารข้อ 1.4.1

SLIDE 04 / 07
👤 1. ลูกค้าผู้ใช้บริการ (1.4.1.3)
  • ก) ริชเมนูบนไลน์: เข้าใช้งานระบบผ่านริชเมนูบน LINE Official Account
  • ข) เลือกช่าง & บริการ: เลือกช่างตัดผมและประเภทบริการที่ต้องการผ่าน LIFF
  • ค) อัปโหลดสลิป: อัปโหลดสลิปหลักฐานการโอนเงินเพื่อแจ้งชำระเงิน
  • ง) รับใบเสร็จ: รับเฟล็กซ์เมสเสจรับเงินอิเล็กทรอนิกส์ (e-Receipt) ผ่านไลน์
✂️ 2. ช่างตัดผม (1.4.1.2)
  • ก) รับแจ้งเตือนชำระเงิน: รับการแจ้งเตือนทันทีเมื่อลูกค้าชำระเงินค่าบริการของตนเองสำเร็จ
  • ข) ตรวจสอบยอดรายได้: ตรวจสอบยอดค่าบริการและส่วนแบ่งค่าคอมมิชชันที่ได้รับแบบเรียลไทม์
  • รับสลิปเคลียร์เงิน: ได้รับสลิปหลักฐานเมื่อเจ้าของร้านตัดรอบเคลียร์เงิน (Settlement)
  • แจ้งเตือนโมฆะบิล: รับแจ้งเตือนทันทีเมื่อมีรายการบิลถูกทำโมฆะ (Void Bill)
💻 3. ผู้ดูแลระบบ/เจ้าของร้าน (1.4.1.1)
  • ก) จัดการช่าง & ค่าคอม: จัดการข้อมูลช่างตัดผมและอัตราส่วนแบ่งค่าคอมมิชชัน
  • ข) จัดการบริการ & ราคา: จัดการข้อมูลประเภทบริการและราคาค่าบริการ (CRUD)
  • ค) ดูแดชบอร์ดสรุปยอดขาย: สรุปยอดขายประจำวันและประจำเดือนผ่านดาต้าสตูดิโอ
  • ง) รับแจ้งเตือนยอดเงิน: รับการแจ้งเตือนยอดเงินและการชำระเงินสำเร็จผ่านไลน์

💻 สถาปัตยกรรมซอฟต์แวร์และคลาวด์ (Software Architecture)

การบูรณาการเครื่องมือพัฒนาและซอฟต์แวร์ระบบคลาวด์ตามเอกสารข้อ 1.4.3 และ 1.4.5

SLIDE 05 / 07
🔍 แตะเพื่อดูภาพขยาย: ผังการทำงานภาพรวมของระบบ (System Architecture)
เครื่องมือและซอฟต์แวร์หลักของระบบ
  • IDE & OS พัฒนา: Antigravity IDE บน Microsoft Windows 11
  • Core Backend: n8n Workflow Automation รันแบบ Self-Hosted บน Railway Server ประมวลผลและส่งข้อมูล
  • LINE Ecosystem: LINE LIFF, LINE Messaging API, LINE Official Account
  • Slip Verification: Slip2Go API ตรวจสอบ QR Code บัญชีผู้รับ และป้องกันสลิปซ้ำ
  • Database & BI: Cloud MySQL บน Railway และ Data Studio (Google Looker Studio)

⚙️ ฮาร์ดแวร์และโครงสร้างพื้นฐาน (Hardware & Infrastructure)

อุปกรณ์เครื่องพัฒนา อุปกรณ์ทดสอบจริง และเซิร์ฟเวอร์คลาวด์ตามเอกสารข้อ 1.4.2 และ 1.4.4

SLIDE 06 / 07
🖥️ 1. ฮาร์ดแวร์ที่ใช้ในการพัฒนา (1.4.2)
  • โน้ตบุ๊กหลักสำหรับพัฒนา (1.4.2.1): โน้ตบุ๊ก เอชพีวิคตัส 16 (HP VICTUS 16) 12th Gen Intel(R) Core(TM) i5-12500H (2.50 GHz) ใช้เป็นเครื่องหลักสำหรับพัฒนาและทดสอบระบบ
  • สมาร์ทโฟนทดสอบจริง (1.4.2.2): สมาร์ทโฟน Nothing Phone (4a) ใช้สำหรับทดสอบการใช้งานจริงบนแอปพลิเคชัน LINE ทั้งฝั่งลูกค้าและช่าง
  • อุปกรณ์ผู้ดูแลระบบ: คอมพิวเตอร์หรือสมาร์ทโฟนที่เชื่อมต่ออินเทอร์เน็ต สามารถเข้าใช้งาน Admin Backoffice ผ่านเว็บบราวเซอร์ได้ทุกที่
☁️ 2. ฮาร์ดแวร์และเซิร์ฟเวอร์คลาวด์ (1.4.4)
  • เรลเวย์เซิฟเวอร์ (Railway Server 1.4.4.1): ใช้รันบริการเอ็นเอทเอ็น (n8n) และฐานข้อมูลมายเอสคิวแอล (MySQL) บนคลาวด์ รวมถึงเป็นเว็บเซิร์ฟเวอร์โฮสต์หน้าเว็บลิฟต์ ตลอด 24 ชั่วโมง
  • ไลน์เซิฟเวอร์ (LINE Server 1.4.5.8): ให้บริการ LINE Messaging API, LIFF สำหรับสื่อสาร รับ-ส่งข้อมูล และยิงการแจ้งเตือนตอบกลับผู้ใช้งาน
  • ความพร้อมใช้งานสูง (High Availability): ทำงานแบบอัตโนมัติบนระบบคลาวด์ ไม่ต้องเปิดคอมพิวเตอร์ทิ้งไว้ที่ร้านตัดผม ประหยัดพลังงานและค่าบำรุงรักษา

🌟 ประโยชน์ที่คาดว่าจะได้รับ (Expected Benefits)

ผลลัพธ์เชิงรูปธรรมต่อธุรกิจร้านตัดผมตามเอกสารข้อ 1.6.1 - 1.6.5

SLIDE 07 / 07
ประโยชน์ 5 ประการตามเอกสารวิชาการ
  • 1.6.1 ได้ระบบเว็บแอปพลิเคชัน (LINE LIFF): อำนวยความสะดวกให้ลูกค้าเลือกช่างและแจ้งชำระเงินผ่าน LINE ได้สะดวกรวดเร็วโดยไม่ต้องลงแอปเพิ่ม
  • 1.6.2 ลดปัญหาสลิปปลอมและยอดไม่ตรง: ตรวจสอบสลิปอัตโนมัติผ่าน Slip2Go API ช่วยลดความเสี่ยงสลิปปลอมและสลิปซ้ำได้
  • 1.6.3 ลดข้อผิดพลาดคำนวณคอมมิชชัน: มีฐานข้อมูล MySQL จัดเก็บข้อมูลธุรกรรมอย่างเป็นระเบียบ และสามารถตรวจสอบย้อนหลังได้
  • 1.6.4 แจ้งเตือนรวดเร็วผ่าน LINE: ลูกค้าได้รับ Flex Message e-Receipt ส่วนช่างและเจ้าของร้านทราบยอดทันที เพิ่มประสิทธิภาพการสื่อสาร
  • 1.6.5 ติดตามผลผ่านแดชบอร์ด Data Studio: เจ้าของร้านติดตามยอดขายและผลการดำเนินงานเพื่อวิเคราะห์และสนับสนุนการตัดสินใจทางธุรกิจได้
