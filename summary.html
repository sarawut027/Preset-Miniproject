การนำเสนอสรุปโครงงาน: ระบบบันทึกรายได้และคำนวณค่าคอมมิชชันช่างตัดผม
แบบเรียลไทม์ผ่านแอปพลิเคชันไลน์

Real-time Barber Income Recording and Commission Calculation System via LINE Application
ผู้จัดทำ: นาย สราวุฒิ อุยยาหาญ (รหัสประจำตัว 674230027, หมู่เรียน 67/44)
สาขาวิชาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยราชภัฏนครปฐม

⚠️ ที่มาและความสำคัญของปัญหา (Problem Statement)

ปัญหาข้อจำกัดของระบบงานเดิมในร้านตัดผม แบ่งเป็น 3 มิติหลัก (เงินเข้า, เงินออก, และการจัดการ)

SLIDE 02 / 07
💸 1. ปัญหาด้านรายรับ (เงินเข้า)
  • ตรวจสอบสลิปด้วยตนเอง: เกิดความล่าช้า ข้อมูลตกหล่นช่วงลูกค้าหน้าร้านหนาแน่น
  • ความเสี่ยงการทุจริต: เสี่ยงต่อการถูกหลอกลวงด้วย "สลิปโอนเงินปลอม" และการนำ "สลิปเก่ามาวนใช้ซ้ำ"
  • ยอดเงินไม่ตรง: ลูกค้าโอนยอดไม่ตรงกับราคาค่าบริการจริงโดยตรวจจับไม่ทันที
🤝 2. ปัญหาการเคลียร์เงินช่าง (เงินออก)
  • คำนวณค่าคอมมิชชันล่าช้า: คิดส่วนแบ่งช่าง (Commission Rate เช่น 50:50) ด้วยมือตอนสิ้นวัน มักเกิดข้อผิดพลาด
  • ขาดระบบตัดรอบเงิน (Settlement): ไม่มีระบบสรุปยอดค้างจ่ายและแนบหลักฐานการโอนจ่ายช่าง
  • ขาดความโปร่งใส: ช่างตัดผมไม่สามารถตรวจสอบยอดเงินสะสมได้แบบเรียลไทม์
🗄️ 3. ขาดระบบจัดการส่วนกลาง (CRUD)
  • บันทึกแยกส่วน: การจดสมุดหรือ Excel ขาดระบบฐานข้อมูลกลางในการ เพิ่ม/ลบ/แก้ไข/ค้นหา
  • แก้ไขบิลผิดพลาดยาก: ขาดระบบ โมฆะบิล (Void Bill) พร้อมระบบ Audit Log ที่ป้องกันการแอบยกเลิก
  • ไม่มีรายงานสรุปผู้บริหาร: เจ้าของร้านขาดแดชบอร์ดสรุปผลประกอบการและกำไรสุทธิแบบสด

🎯 วัตถุประสงค์ของโครงงาน (Project Objectives)

5 เป้าหมายหลักในการพัฒนาระบบเพื่อแก้ปัญหาอย่างตรงจุดและวัดผลได้จริง

SLIDE 03 / 07
1. ระบบรับชำระเงิน & ตรวจสลิป (LINE LIFF)

เพื่อพัฒนาเว็บแอปพลิเคชันผ่านระบบลิฟต์ (LINE LIFF) สำหรับรับแจ้งชำระเงิน ตรวจสอบสลิปโอนเงินอัตโนมัติ (Slip2Go API) และออกใบเสร็จรับเงินอิเล็กทรอนิกส์ (e-Receipt Flex Message) ผ่านแอปพลิเคชันไลน์

2. ระบบตัดรอบเคลียร์เงินช่าง (Settlement & Payout)

เพื่อพัฒนาระบบคำนวณและตัดรอบเคลียร์เงินส่วนแบ่งค่าคอมมิชชันให้แก่ช่างตัดผม (Barber Commission Settlement) พร้อมบันทึกหลักฐานการจ่ายเงินและส่งสลิปแจ้งเตือนช่างอย่างโปร่งใส

3. ระบบบริหารจัดการหลังบ้าน (Admin Full CRUD)

เพื่อพัฒนาระบบบริหารจัดการข้อมูล (Admin Backoffice) ที่รองรับการจัดการแบบครบวงจร (CRUD) ทั้งข้อมูลช่างตัดผม, รายการบริการ, ประวัติธุรกรรม, และระบบโมฆะบิล (Void Bill)

4. แดชบอร์ดสรุปผลการเงิน (Looker Studio) & ประเมินผล

เพื่อพัฒนาระบบรายงานและแดชบอร์ดสรุปผลทางการเงิน (Google Looker Studio) สำหรับวิเคราะห์ยอดขายรวม ยอดจ่ายช่าง และรายได้สุทธิแบบเรียลไทม์ พร้อมประเมินความพึงพอใจของผู้ใช้งาน

📐 ขอบเขตของระบบ (System Scope)

ขอบเขตฟังก์ชันการทำงานครอบคลุม 3 กลุ่มผู้ใช้งานหลัก (ลูกค้า, ช่างตัดผม, เจ้าของร้าน)

SLIDE 04 / 07
👤 1. ฝั่งลูกค้า (Customer)
  • LINE Official Account: ใช้งานผ่าน Rich Menu โดยไม่ต้องโหลดแอปใหม่
  • LINE LIFF Form: เลือกช่างตัดผมและรายการบริการพร้อมดูราคา/รูปตัวอย่าง
  • 2 ช่องทางชำระเงิน: เงินสดหน้าร้าน (Cash) หรือ สแกนโอนเงิน (PromptPay QR)
  • Slip Verification: สแกนตรวจยอดเงิน, บัญชีผู้รับตรง, และกันสลิปซ้ำ 100%
  • e-Receipt: รับใบเสร็จ Flex Message ยืนยันในแชททันที
✂️ 2. ฝั่งช่างตัดผม (Barber)
  • Real-time Income Alert: รับการแจ้งเตือนยอดเงินและค่าคอมมิชชันเข้า LINE ส่วนตัวทันทีเมื่อมีบิลเข้า
  • Payout Slip Alert: ได้รับสลิปหลักฐานเมื่อเจ้าของร้านตัดรอบเคลียร์เงิน
  • Void Bill Alert: ได้รับแจ้งเตือนทันทีเมื่อมีบิลถูกสั่งโมฆะหรือยกเลิก
  • Profile & Services: ดูรหัสประจำตัวช่างและรายการบริการผ่านหน้าร้าน
💻 3. ฝั่งเจ้าของร้าน (Admin)
  • CRUD ช่าง & บริการ: จัดการข้อมูลช่าง, กำหนด % ค่าคอมมิชชัน, ปรับราคาบริการ
  • จัดการบิล & โมฆะบิล: ดูประวัติธุรกรรม และสั่งโมฆะบิลพร้อมระบบ Audit Log
  • ตัดรอบเคลียร์เงิน: สรุปยอดค้างจ่ายช่าง แนบสลิป และอัปเดตสถานะ Settled
  • BI Dashboard: ดูรายงานยอดขายและรายได้สุทธิผ่าน Looker Studio

💻 สถาปัตยกรรมซอฟต์แวร์และคลาวด์ (Software Architecture)

การเชื่อมโยงระบบแบบไร้รอยต่อ (End-to-End Workflow) ระหว่าง LINE, n8n, APIs และ Cloud Database

SLIDE 05 / 07
🔍 แตะเพื่อดูภาพขยาย: ผังการทำงานภาพรวมของระบบ (System Architecture)
5 เสาหลักเทคโนโลยีของระบบ
  • Core Backend: n8n Workflow Automation รันแบบ Self-Hosted บน Railway Cloud จัดการ Webhook และตรรกะระบบ
  • Frontend: LINE LIFF SDK (HTML5, Tailwind CSS, JavaScript) และ Admin Backoffice
  • Communication: LINE Messaging API ส่ง e-Receipt และการแจ้งเตือนแบบ Flex Message
  • Payment Security: Slip2Go API ตรวจสอบ QR Code ธนาคาร ยอดเงิน และเลขอ้างอิงสลิป
  • Database & BI: MySQL Database บน Railway Cloud และ Google Looker Studio

⚙️ ฮาร์ดแวร์และโครงสร้างพื้นฐาน (Hardware & Infrastructure)

การจัดเตรียมสภาพแวดล้อมทั้งฝั่งอุปกรณ์เครื่องผู้ใช้ (Client) และโครงสร้างคลาวด์ (Cloud 24/7)

SLIDE 06 / 07
🖥️ 1. ฮาร์ดแวร์ฝั่งพัฒนาและเครื่องผู้ใช้ (Client Hardware)
  • คอมพิวเตอร์พัฒนาหลัก: โน้ตบุ๊ก HP VICTUS 16 (12th Gen Intel Core i5-12500H, RAM 16GB, Windows 11) สำหรับเขียนโปรแกรมและออกแบบระบบ
  • อุปกรณ์ทดสอบฝั่งลูกค้า/ช่าง: สมาร์ตโฟน VIVO V27 5G (Android) และอุปกรณ์ iOS/Android สำหรับทดสอบการทำงานบน LINE
  • อุปกรณ์ฝั่งเจ้าของร้าน: คอมพิวเตอร์/แท็บเล็ต/สมาร์ตโฟนที่เชื่อมต่ออินเทอร์เน็ต สามารถเปิดใช้งานระบบผ่านเว็บบราวเซอร์ได้ทุกที่
☁️ 2. โครงสร้างพื้นฐานระบบคลาวด์ (Cloud Infrastructure 24/7)
  • Railway Cloud Platform: เซิร์ฟเวอร์คอนเทนเนอร์บนระบบคลาวด์มาตรฐานสากล สำหรับรัน n8n Workflow Engine และ MySQL Database ให้บริการตลอด 24 ชั่วโมง
  • LINE Developer Platform: เซิร์ฟเวอร์คลาวด์ของ LINE สำหรับบริหารจัดการ Channel Webhook และ LINE Messaging Gateway
  • High Reliability & Zero Setup: ไม่ต้องเปิดเครื่องคอมพิวเตอร์ทิ้งไว้ที่ร้านตัดผม ลดต้นทุนฮาร์ดแวร์และค่าบำรุงรักษา

🌟 ประโยชน์ที่ได้รับ & ลิงก์เชื่อมโยง (Key Benefits & Links)

SLIDE 07 / 07
ผลลัพธ์และความคุ้มค่าของระบบ
  • ด้านความปลอดภัยทางการเงิน: ป้องกันการใช้สลิปปลอมและสลิปวนใช้ซ้ำได้ 100% ด้วย Slip2Go API
  • ด้านความโปร่งใสและประสิทธิภาพ: ช่างได้รับแจ้งยอดรายได้ทันที และมีระบบตัดรอบเคลียร์เงิน (Settlement) ตรวจสอบได้ชัดเจน
  • ด้านประสบการณ์ลูกค้า (UX): ลูกค้าชำระเงินสะดวกผ่าน LINE ได้ใบเสร็จ e-Receipt สวยงาม ไม่ต้องลงแอปใหม่
  • ด้านการบริหารจัดการ: เจ้าของร้านมีแดชบอร์ดสรุปรายได้ ยอดขายช่าง และสถิติต่าง ๆ ในหน้าจอเดียว
